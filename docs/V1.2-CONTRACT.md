| 区域 | 内容 | 要求 |

## 3. 我的技能模块（R2）

### 3.1 页面
- `site/skills.html`：nav 新增「技能 / Skills」（8 页 + 404 均更新 nav）；title/desc/OG/canonical；`body[data-page="skills"]`。
- 结构：Hero（技能是什么、与本项目关系）→ 筛选（全部/我的/官方/社区 + 分类）→ 技能卡片网格 → 「使用引导」modal → 「分享技能」→ 提交区（上传/共享）→ 安装说明。
- 卡片：名称、作者、一句话描述、分类/标签、来源徽标（我的/官方/社区）、stars、许可证、更新时间、「使用引导」「分享」按钮、源码链接。
- 空态/加载/错误态；移动端适配；a11y（modal focus trap/Esc/aria-live）。

### 3.2 数据结构：`data/skills.json`（schemaVersion 1）
```jsonc
{
  "schemaVersion": 1,
  "generatedAt": "2026-11-03T00:00:00.000Z",
  "source": "curated+github",
  "count": 8,
  "items": [
    {
      "id": "one-sentence-project",
      "name": "One-Sentence Project",
      "nameZh": "一句话交付项目",
      "description": "Turn a one-sentence request into a deployable public tracker site.",
      "descriptionZh": "把一句话需求变成可上线的公域数据站。",
      "category": "methodology",           // methodology | data | writing | design | dev | research | other
      "author": "chengxi-Z",
      "repo": "chengxi-Z/llm-pulse",       // 可空
      "url": "https://github.com/chengxi-Z/llm-pulse/tree/main/skills/one-sentence-project", // SKILL 目录/文档
      "license": "MIT",
      "stars": null,                       // 可空（数字）
      "updatedAt": "2026-11-03T00:00:00.000Z",
      "sourceType": "mine",                // mine | official | community
      "tags": ["methodology", "static-site", "github-pages"],
      "featured": true,
      "lang": "en",                        // en | zh | multi
      "whenToUse": "一句话需求做公域数据站时...",
      "whenNotToUse": "通用 Web 应用/后端/实时系统...",
      "install": { "target": "~/.dsh/skills/one-sentence-project", "command": "Copy-Item -Recurse skills/one-sentence-project \"$env:USERPROFILE\\.dsh\\skills\\one-sentence-project\"" },
      "usageSteps": ["复制目录到本机 skills 目录", "对话中描述一句话需求", "按 Skill 的 POC→MVP→Release 流程验收"],
      "skillPath": "skills/one-sentence-project/SKILL.md"
    }
  ]
}
```
- `nameZh/descriptionZh/whenToUseZh...` 规则：数据本身双语字段（en 为主 + Zh 后缀）；前端按语言取，缺失回退另一语言。i18n 词典只负责 UI chrome，不翻译数据。
- 初始内容 ≥8 条：1 条 `mine`（one-sentence-project）+ ≥4 条 `community`（真实公开 Agent Skills 仓库/合集）+ ≥2 条 `official`（Anthropic/平台官方 skills 资源）；stars 通过 GitHub API 获取（skill-author 负责核实存在与链接可用）。

### 3.3 使用引导 modal
- 内容：一句话价值、适合/不适合、安装（复制到 `~/.dsh/skills/` / `~/.claude/skills/` / 通用 Agent skills 目录）、触发示例、文件结构（SKILL.md/references/scripts）、自检命令、源码链接、分享按钮。
- 复制按钮（Clipboard API + fallback）；键盘可关闭；`aria-modal`/focus trap。

### 3.4 上传 / 共享流程（静态站，无后端）
页面「提交你的技能」区提供三条路径：
1. **GitHub Issue 提交**：按钮打开 `https://github.com/chengxi-Z/llm-pulse/issues/new?template=skill-submission.yml`（新增 Issue Form 模板，字段：技能名/作者/分类/一句话/链接/许可证/使用说明/是否原创）；维护者审核后合入 `data/skills.json`。
2. **下载 JSON 模板**：客户端根据表单字段生成 `skill.json` 下载（Blob），供 PR 使用。
3. **Fork & PR 指引**：3 步说明 + 指向 `CONTRIBUTING.md#skills` 章节 + 数据 schema 链接。
- 明确写出「本站无后端，提交通过 GitHub 审核后上线」；审核标准（真实可用、许可证、无恶意内容、含使用引导）。
- 同步更新 `CONTRIBUTING.md`（英文）Skills 贡献章节与 `.github/ISSUE_TEMPLATE/skill-submission.yml`。

### 3.5 分享技能
- 每张技能卡「分享」→ 分享卡 kind=skill（技能名 + 一句话 + 安装目标 + 站点/GitHub 地址 + 二维码可选）。
- 复制文案：技能名 + 价值 + 安装命令 + 站点地址。

## 5. 首页可视化仪表盘（R4）

### 5.1 位置
首页顺序调整为：`hero` → **`#overview-dashboard`（新）** → `highlights`（本期要目）→ `本周新模型` → 榜单 → 动态 → explore → subscribe。
- 标题区：`概览 / OVERVIEW` + 一句话「用数字看懂此刻的模型世界」+ 数据更新时间。

### 5.2 组件（全部数据来自 `data/models.json` + `data/meta.json` + `data/rankings.json`，不得造假）
1. **KPI 数字墙**（6 项，count-up 600–1200ms，进入视口触发一次）：
   - 收录模型 `models.length`；副文案「覆盖 N 家厂商」
   - 累计上下文容量 `sum(contextWindow)` → 人类可读（如 `1.6B tokens`）；副文案「所有模型窗口之和」
   - 近 7 天新增模型（releaseDate 在 7 天内计数）；副文案「最新 N 天」
   - 公开榜单 `boards.length`；副文案「含真实来源 N 个」
   - 数据源正常 `meta.stats.sourcesOk / sources总数`；副文案「每日自动刷新」
   - 动态条目 `news.length`；副文案「来自 N 家官方源」
   - 每项含小标签（uppercase 金色）+ 数字（衬线大号）+ 说明；无数据时显示「—」且不报错。
2. **近 12 周模型发布趋势**（sparkline / area chart，纯 SVG）：
   - 按 `releaseDate` 聚合周（周一为界），近 12 周计数；line + 渐变面积 + 端点圆点；hover/focus 显示 `周起始日期 · N 个`；x 轴仅显示首/中/末标签避免拥挤。
3. **厂商分布 Top 8**（横向条）：按 org 计数排序取前 8；条宽 = 占比；显示名称 + 数量 + 百分比；hover 高亮；tokens 颜色。
4. **输出价格分层**（横向/纵向条）：档位 `免费 / <$1 / $1–5 / $5–15 / ≥$15`（USD/1M output），计数 + 占比；无价格模型不计入并在脚注说明。
5. **微动效**：IntersectionObserver 触发：数字 count-up（ease-out）、条宽从 0 展开、SVG path 描边；总时长 ≤1.2s；`prefers-reduced-motion: reduce` 时直接渲染终值；不得弹跳/闪烁；动画只跑一次。
6. **交互**：图表 hover/focus tooltip（纯 DOM，无需库）；移动端可点按；键盘可达（tabindex 或表格替代）。
7. **性能**：新增 JS ≤12KB raw、CSS ≤8KB raw；无外链库/字体/图片；首屏不因 dashboard 阻塞数据加载（dashboard 在数据就绪后渲染；失败只影响该区块）。

### 5.3 视觉（ui-designer）
- 克制的「数据杂志」风格：细金线坐标轴、小字 uppercase 标签、衬线大数字、纸面卡片；不要霓虹/发光/高饱和；动效柔和不弹跳；与 5 主题 token 兼容（颜色全部 token 化）。
- 桌面 2 列/3 列网格；移动端单列；深色主题 OK。
