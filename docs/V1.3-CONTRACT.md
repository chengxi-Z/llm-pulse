### 1.2 近 12 周发布 — 柱状图
- 12 根竖柱（周一起算），柱顶数值（hover/focus 才显示 tooltip，避免拥挤；最大值可常显）。
- 3 条横向网格线 + y 轴刻度（0/中/最大），x 轴 12 个周标签（MM.DD，窄屏可隔一显示）。
- 虚线均值线 + 标签「周均 N 个」；柱体渐变用 `--highlight`；入场上长动画（transform: scaleY，≤0.9s，stagger ≤40ms）。
- hover/focus tooltip：`09.21 周 · N 个新增模型`；键盘可聚焦（tabindex + role）。

### 1.3 输出价格分层 — 环形饼图（donut）
- 5 档：免费 / <$1 / $1–5 / $5–15 / ≥$15（输出价 USD / 1M tokens；未公开价格不计）。
- 环形（半径外 88 / 内 54，SVG path arc），5 色取自主题 token（highlight 系 + muted 系，保证 5 主题可读）。
- 中心文案：`451 模型` + 小字 `444 已标价`（动态计算，非硬编码）。
- 图例：色点 + 档位 + 数量 + 占比（右/下排列；对齐成列）；hover 高亮对应扇区与图例（class 切换）。
- 入场上：从 0 到比例扫过（transform rotate 或 stroke-dashoffset），≤1s；reduced-motion 直接终值。

### 1.4 AI 模型斩杀线（新，重点观感）
- **定义（页面必须明示规则）**：以「输出价格中位价」为斩杀线——`Median = P50(输出价/1M tokens)`，当前本地数据为 **$2.00/1M**（动态计算，不硬编码）。斩杀线以上=高价区（"斩杀区"），以下=生存区；注明「规则可调整；非质量评价」。
- **可视化**：全宽卡片内一条水平价格轴（**log 刻度** 0 → 最大价），每个已标价模型一根 3px 竖细条（按价格定位），颜色：≤斩杀线=`--highlight`（生存），>斩杀线=`--muted`/低饱和红（斩杀），透明度区分；**虚线垂直斩杀线** + 标签 `斩杀线 $2.00/1M`（金色）；
- **注释**：`232 个模型 ≤ 斩杀线（52.3%）` / `212 个 > 斩杀线`；轴刻度 `$0.01 / $1 / $10 / $100`（log）；hover tooltip 显示模型名 + 输出价；键盘可聚焦关键点（或表格替代）。
- 数据：`models.json` 中 `pricing.output` 非空；价格 0（免费）单列在轴左端并计入生存区。
- 说明文案（i18n）：斩杀线定义、统计口径、「不构成质量/推荐评价」。

### 1.5 AI 话题热榜（新）
- 数据来源（真实计算，无造假）：近 **60 天** `news.json` 的 `title+summary+tags` 关键词匹配 + `models.json` 能力/模态标签，8 个主题：
  `开源权重 / 长上下文 / 推理 / 多模态 / Agent / 价格战 / 安全 / 微调`
  （计数规则在 `dashboard.js` 常量中，可维护；页面注明统计窗口与口径）。
- 展示：Top 6–8 排名列表：名次（01/02…）+ 话题名 + 热度条（按最大值归一化，宽度动画）+ 计数（如 `32 条动态 · 387 模型`）+ 箭头「去看」。
- 交互：hover 高亮；点击话题 → `news.html?tag=<tag>`（site-mvp 需给 news 页增加 `?tag=` 初始筛选支持；无匹配时回退到全部并提示）。键盘可达。
- 风格：克制的热榜（金色名次、细条、留白），不要"电商热榜"红黄刺眼。

### 1.6 动效与性能
- 动效：IntersectionObserver 入场一次；柱/弧/条/数字 ≤1s，stagger ≤40ms；`prefers-reduced-motion` 直接终值；不弹跳。
- 性能：dashboard JS 增量 ≤6KB（当前 15.8KB → 目标 ≤22KB，放宽需记录）；每页 CSS 预算 ≤120KB（**需拆分**：见 §3.3）。

3. **图表卡头部**：标题与右上说明基线对齐；同排两卡等高、内边距一致。
4. **全局**：1440/1280/1024/834/768/390/360 下导航、筛选条、卡片网格、页脚列、表格滚动、浮动按钮（AI 助手/回顶）遮挡；任何横向溢出都不允许。
5. 其他所有"看起来错位"的问题按自动审计 + 截图逐项清零。

### 3.2 验收方式（Lead 自动布局审计，成员按报告修）
Lead 用 CDP 脚本在 7 个宽度下对全部页面检查并输出问题清单：
- 横向溢出 `scrollWidth > innerWidth+1`；
- 指定网格同行卡片高度差 >2px（`skills-grid`、`model-grid`、`project-grid`、`dash-card` 行、KPI 行）；
- 同行卡片底部按钮/操作区 y 差 >2px（skills/project/model 卡）；
- KPI 数字 top 差 >2px、标题/说明基线差 >2px；
- 图表 SVG 容器宽高与卡片内容区偏差 >2px；
- 浮动按钮与内容关键块重叠（定义：与卡片文字区域相交 >4px）。
审计清单 0 问题方可发布；发布前 Lead 再人工看 1440/1024/390 三档截图。

### 3.3 CSS 拆分（必须）
- 当前全站 raw 119.73KB 接近 120KB 上限；v1.3 新增图表样式需拆分：
  - `site/assets/css/components.css` 保留通用组件（≈减 8-10KB）；
  - 新增 `site/assets/css/dashboard.css`（仅 index.html 引入）；
  - 新增 `site/assets/css/skills.css`（仅 skills.html 引入）；
  - 其他页仍只引通用 CSS。
- 每页 CSS raw ≤120KB（一般页 ≈110KB；index/skills ≈118KB）；gzip 目标 ≤26KB。
- 页面 `<link>` 由 site-mvp 加（dashboard.css 只 index，skills.css 只 skills）。

### 3.4 技能卡等高（具体修法）
- `.skills-grid { align-items: stretch; }`；`.skill-card { display:flex; flex-direction:column; height:100%; }`；`.skill-card-footer/.skill-actions { margin-top:auto; }`
