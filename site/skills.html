安装与使用

Agent Skills 是纯文本目录：复制到本机 skills 目录，Agent 会在合适的时候自动加载；也可以在对话里直接点名调用。

01

复制技能目录到本机 Agent skills 目录

常见 Agent skills 目录
~/.dsh/skills/ · ~/.claude/skills/ · 你的 Agent 的 skills 目录

02

在对话中描述你的任务，或直接点名使用该技能

按技能内的流程执行，并用自检命令验证结果

自检命令

node skills/one-sentence-project/scripts/check-project.mjs --self

03 提交你的技能 SUBMIT

让更多人用上它

本站无后端：技能通过 GitHub Issue 或 Pull Request 提交，维护者审核后合入 data/skills.json 并上线。

路径一 · GitHub Issue

打开技能提交表单，填写名称、作者、分类、链接与使用说明。

打开 Issue 表单

路径二 · 下载 JSON 模板

生成一份 skill.json 模板，填写后随 PR 提交。

路径三 · Fork & PR

Fork 仓库，按数据 schema 修改 data/skills.json，然后提交 PR。

  1. Fork 本仓库并创建分支
  2. 按 data/skills.json 的 schema 添加条目
  3. 提交 PR，等待维护者审核
阅读贡献指南

本站无后端，技能经由 GitHub 审核后上线。

贡献指南

审核标准

  • 真实可用：有可访问的源码或文档链接
  • 许可证明确（MIT / Apache-2.0 等）
  • 无恶意内容，不收集用户数据
  • 包含使用引导（适用 / 不适用 / 使用步骤）
