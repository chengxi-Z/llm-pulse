Install and use

Agent Skills are plain-text folders: copy one into your local skills folder and your agent loads it when relevant — or invoke it by name in chat.

01

Copy the skill folder into your agent's skills directory

Common Agent skills folders
~/.dsh/skills/ · ~/.claude/skills/ · Your agent's skills folder

02

Describe your task in chat, or name the skill explicitly

Follow the steps inside the skill and verify with its self-check command

Self-check command

node skills/one-sentence-project/scripts/check-project.mjs --self

03 Submit your skill SUBMIT

Put it in more hands

This site has no backend: submit a skill through a GitHub Issue or Pull Request; after review it is merged into data/skills.json and published.

Option 1 · GitHub Issue

Open the skill submission form and fill in the name, author, category, links and usage notes.

Open the Issue form

Option 2 · Download the JSON template

Generate a skill.json template, fill it in, and include it in your PR.

Option 3 · Fork & PR

Fork the repository, add your entry to data/skills.json following the schema, then open a PR.

  1. Fork this repository and create a branch
  2. Add an entry that follows the data/skills.json schema
  3. Open the PR and wait for maintainer review
Read the contribution guide

No backend here — skills go live after GitHub review.

Contribution guide

Review criteria

  • Real and usable: an accessible source or documentation link
  • A clear license (MIT / Apache-2.0, etc.)
  • No malicious content and no user-data collection
  • Includes a usage guide (when to use / when not to use / steps)
