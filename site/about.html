01 方法 METHOD

数据是如何来的

采集 → 归一化 → 校验 → 发布，全程脚本化、可复现。

  1. 采集

    通过公开 API、数据集与 RSS 获取一手信息：模型目录、价格、榜单、厂商动态与社区项目。失败自动重试并保留原始快照。

  2. 归一化

    统一字段、单位与时区：价格统一为 USD / 1M tokens，时间统一为 ISO 8601，文本去除 HTML，ID 使用稳定 slug。

  3. 校验

    按数据合约检查必填字段、枚举值与引用一致性；数量异常时阻断发布，避免用错误数据覆盖可用数据。

  4. 发布

    生成 JSON 与 RSS / Atom / JSON Feed，由 GitHub Actions 每日自动刷新并部署为静态站点。前端只读，不做二次编造。

透明与克制

每个数据块都显示「更新时间 + 来源」。当来源不可达或字段缺失时，站点显示降级状态或空态，而不是猜测或补全。

  • 只展示公开可引用数据，保留原始链接。
  • 不抓取登录后内容，不保存全文，可申请移除。
  • 不做用户画像、不植入追踪脚本。
本站是个人维护的非商业项目，数据可能存在延迟或口径差异，请以原始来源为准。
