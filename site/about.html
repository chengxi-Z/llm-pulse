01 Method METHOD

How the data is made

Collect → normalize → validate → publish, fully scripted and reproducible.

  1. Collect

    Pull first-hand information from public APIs, datasets, and RSS: model catalogs, pricing, leaderboards, vendor updates, and community projects. Failures are retried automatically and raw snapshots are kept.

  2. Normalize

    Unify fields, units, and time zones: pricing in USD / 1M tokens, timestamps in ISO 8601, HTML stripped from text, and stable slugs for IDs.

  3. Validate

    Check required fields, enum values, and referential consistency against the data contract. When counts look abnormal, publishing is blocked so bad data can't overwrite good data.

  4. Released

    Generate JSON plus RSS / Atom / JSON Feed, refreshed daily by GitHub Actions and deployed as a static site. The frontend is read-only and never re-invents content.

Transparency and restraint

Every data block shows an update time and source. When a source is unreachable or a field is missing, the site shows a degraded or empty state instead of guessing or filling gaps.

  • Show public, citable data only, with original links preserved.
  • No crawling behind logins, no full-text storage; removal requests are honored.
  • No user profiling and no tracking scripts.
This is a personally maintained, non-commercial project. Data may lag or use different definitions; always defer to the original source.
