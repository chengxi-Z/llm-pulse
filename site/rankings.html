01 Reading guide HOW TO READ

What a leaderboard really measures

A model can rank very differently from one board to the next — read the metric first, then the rank.

Metric

Start with the metric

Win rate, capability index, benchmark accuracy, price, and context length all measure different things. Before comparing across boards, check the units and whether higher or lower is better.

Source

Every entry credits its source

Board data comes from public pages or datasets; each panel includes source links and update times. If a source is unreachable, the whole board is marked degraded in the data-source status — we never pass old data off as new.

Principle

Aggregation, not endorsement

AI Pulse doesn't run evaluations or judge the boards' methods. A ranking reflects one public result from one source at one point in time; cite the original source.
